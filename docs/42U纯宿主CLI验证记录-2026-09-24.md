# 42U 纯宿主 CLI 验证记录（2026-09-24）

## 范围

本记录对应项目版本 `0.3.0`、基础 ABI v3 和独立 CLI manifest v1。验证对象包括：

- 不创建实例的插件发现与 DSO 所有权移交；
- 插件声明根参数、一级子命令、局部参数和 numeric handler；
- owner-local 只读配置快照与 `iconfig`；
- CLI11 `2.7.2` 动态解析及 42U 受限语法；
- 确定性 JSON payload、原样业务输出、退出码和显式 shutdown；
- manifest、配置和分配失败的拒绝与回滚路径。

## 构建与测试

普通 Debug：

```bash
xmake f -o build -m debug --sanitizer=none --yes
xmake -v
xmake test -v
```

AddressSanitizer：

```bash
xmake f -o build-asan -m debug --sanitizer=address --yes
xmake
ASAN_OPTIONS=detect_leaks=0 xmake test -v
```

UndefinedBehaviorSanitizer：

```bash
xmake f -o build-ubsan -m debug --sanitizer=undefined --yes
xmake
UBSAN_OPTIONS=print_stacktrace=1:halt_on_error=1 xmake test -v
```

三组配置均为 **15/15 测试目标通过**。ASan 关闭 leak 检测，是因为框架对无法证明静默的插件采用进程期资源保留策略；内存安全错误仍由 AddressSanitizer 检查。

## 新增持久测试

| 目标 | 覆盖内容 |

| `cli_abi_test` | manifest/config 布局、入口签名、flags、IID 和 mock `iconfig` |

| `cli_e2e_test` | `--version` 无发现、帮助/解析错误不 create、非法/不支持 manifest、旧 v3 无 manifest 兼容、handler 缺失、业务与 shutdown 双失败、真实 DSO 生命周期、配置隔离、原样输出和输出设备失败 |

原有 ABI、runtime、boot、reentrant、safety、lease、event、withdraw 和 integration 测试保持通过；旧 v1/v2 插件仍被 ABI v3 宿主拒绝，无 manifest 的 v3 插件仍可加载。

## 审核修复

多 Agent 独立审核发现并修复：

- POSIX 可选 manifest 符号查找混淆“缺少符号”和其他 loader 错误；
- catalog 收紧基础 ABI plugin ID、遗漏 config key 冲突和位置 required 顺序；
- CLI TEXT 未校验 UTF-8，可能产生非法 JSON/config view；
- `host::adopt()` 在 create 成功后记录回滚 ID仍可能分配；
- stdout 写入失败仍返回成功；
- 宿主自动给业务结果补换行；
- 固定位置参数无法表达以 `-` 开头的文本。

修复后重新执行普通 Debug、ASan 和 UBSan 全量测试。

## 当前边界

- 仍是可信、本地、同进程、单控制线程、同步调用模型；没有沙箱或崩溃隔离。
- 第一版只执行一个有限时长命令；常驻任务、取消、轮询和流式输出协议尚未实现。
- CLI manifest v1 只提供 TEXT、FLAG、固定位置 TEXT 与 repeatable TEXT 的受限组合。
- Windows、macOS 和 32 位 profile 尚未完成本轮等价验证；`cli_runtime_test` 的精确 DSO/分配故障注入当前仅在非 Windows 目标构建。
- CLI11 的 requirement 受 xmake 语法限制必须声明在项目根作用域，但只有 `42uhost_cli` 通过 `add_packages` 获得其头文件；`42u`、插件 ABI、示例和 fixture 不编译或链接 CLI11。
